# Hard Points & Known Errors

Recurring corrections from practice. Use this file to seed review drills, not as a failure log. Keep the focus on repeated mistakes, vague fallback habits, and register drift.

---

## 退役済み: 再導入しない

| Avoid | Replace With | Note |
| --- | --- | --- |
| `把握しました` | start directly with the status or action | Retired anchor; no need to drill it |
| 汎用の `進めます` | `調整します` / `実施します` / `検討します` / `行います` | Pick the real action |
| 汎用の `対応` | `確認` / `反映` / `修正` / `対策` / `調整` | Avoid vague catch-all wording |
| `〇〇の件` | say the topic directly | Drop the stock opener |
| `第一案` / `第二案` | `この進め方` / `この方針` | Reusable recommendation framing is higher value |
| `〜次第` | `〜たら` / `〜てから` / direct sequencing | Keep the ceiling direct and compact |
| `現状を認識しております` | state the conclusion directly | Retired analytical opener |

Also avoid humble loops such as `〜したく存じます` and `〜させていただければ幸いです`.

## Particle Errors

| Error | Correct | Note |
| --- | --- | --- |
| `原因を分かっていません` | `原因が分かっていません` | `分かる` takes `が` |
| `設定は原因の可能性があります` | `設定が原因の可能性があります` | `が` marks the possible cause |
| `この内容が誰が担当ですか` | `この内容は誰が担当ですか` | topic particle `は` |
| `誰が聞けばいいですか` | `誰に聞けばいいですか` | target takes `に` |
| `合っている方針に` | `既存の方針に合っている` | `合う` takes `に` |

## Verb Form Errors

| Error | Correct | Note |
| --- | --- | --- |
| `終わってますせん` | `終わっていません` | Keep `て` + `いません` |
| `終わってたら連絡します` | `終わったら連絡します` | Past conditional, not progressive |
| `確認してたら返事します` | `確認してから返事します` | Sequence, not progressive |
| `聞きてみます` | `聞いてみます` | `聞く` → `聞いて` |
| `分かりたら共有します` | `分かったら共有します` | `分かる` → `分かったら` |
| `問題が見つけていません` | `問題は見つかっていません` | `見つかる` is intransitive |

## Word Choice & Register

| Issue | Avoid | Prefer | Note |
| --- | --- | --- | --- |
| Escalation phrase | `エスカレーションします` | `必要なら上長に相談します` | Natural Japanese alternative |
| Risk wording | `リスク` | `懸念点` / `恐れ` | Prefer native wording when practical |
| Formal `いい` | `よし` | `よい` | `よし` is not the formal adjective |
| Judgment framing | `判断に迷っています` | `判断材料が不足しています` | Objective framing fits the target register |
| Permission phrase | `よろしですか` | `よろしいですか` | Keep the full form |
| Receive phrase | `いただけますま` | `いただけますか` | Final character error |
| Coordination framing | manager-style pressure language | `工程をすり合わせて、開発の停滞を防ぎます` | Prefer peer-level alignment |
| Discrepancy term | imported / shorthand labels | `食い違い` | Keep plain-Japanese mismatch framing |
| Scope control phrasing | broad generic scope-cut wording | `実装範囲を絞ります` | More precise |
| Temporary framing | using `一旦` on a noun | `一旦` for actions / `一時的な` for nouns | Keep the distinction active |
| Recommendation framing | `第一案` / `第二案` | `この進め方` / `この方針` | Reusable and less artificial |

## Structural / Nuance Errors

| Error | Correct | Note |
| --- | --- | --- |
| `も` dropped: `相談していいですか` | `相談してもいいですか` | Keep `も` in permission pattern |
| `て` dropped: `相談さしてください` | `相談させてください` | Keep `て` before `ください` |
| `方` dropped: `進めを相談させてください` | `進め方を相談させてください` | `進め方` = how to proceed; `方` is part of the noun |
| `と` dropped before `思います` | `〜と思います` | `と` marks the content of the thought |
| `も` + `少ない` misread | `手戻りが少ない` = "few rework steps" | `少ない` = few/little; it is not negation |
| Parallel structure break | `影響範囲が小さいことと、後から変更しやすいことです。` | Keep reasons parallel with `〜ことと、〜ことです` |
| `理由が二つあります` in recommendation | `理由は二つあります` | `は` preferred in this recommendation pattern |
| `〜の観点から` | personal preference framing | objective criterion framing | Use this to defend architecture from a stated perspective, not to express taste |
| `変更しやすい` as noun | `変更しやすいこと` | Nominalize with `こと` |
| `技術戦略則り` | `技術戦略に則り` | Keep `に` |
| `費用対効果が見極めます` | `費用対効果を見極めます` | Object takes `を` |
| `歩調を合わせ` break | `他開発部署と歩調を合わせ、` | Keep the phrase as one chunk |
| `見落としていた` pause | Pronounce as one phrase, no pause after `見落として` | |
| `お待ちくだらい` | `お待ちください` | Final character |

## Pronunciation & Voice-Input Notes

These are not errors unless the session is explicitly about writing.

| Situation | Note |
| --- | --- |
| `まず` | Pronounced `ma-zu`, not `ma-tsu` |
| `転倒者` (voice input) | Intended `担当者`; ignore when spoken intent is clear |
| `仕様変更` IME trap | `仕様`, not `使用`; not a spoken error |
| `堅牢性` | Still a live pacing and retrieval pressure point; drill inside full sentences |
| Mac IME okurigana variants | Accept when the spoken form is correct |
| Katakana words | Treat meaning as known; do not waste time on katakana pronunciation drills |
